# Third-party data and service notices

The MIT license applies to this repository's code; it does not grant rights to third-party data or APIs.

Before using or redistributing a source, record its exact URL, access date, current license/terms, attribution, redistribution rights, retention restrictions, and review status in `config/source_licences.csv`.

Candidate sources (all **to review**, not approved for production):
- OurAirports airport reference data: verify current license and attribution.
- ADS-B provider such as adsb.lol: verify API scope, acceptable use, rate limits, attribution, and database obligations.
- AAI / DGCA reports: verify each report's authority, reuse terms, and reporting period.
- Aviation Weather Center / Iowa Mesonet: verify access policy, station coverage, attribution, and retention.

A public URL does not automatically mean unrestricted reuse. Update this file as source reviews are completed.
